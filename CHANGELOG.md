## [0.1.0] - 2026-10-16

### Added

- Asynchronous, line-oriented TCP server powered by Tokio.
- Actor-based session and world-state management.
- JSON world loading with rooms, exits, and items.
- Built-in movement, chat, help, inventory, examination, and item-transfer commands.
- Extensible command and event-hook registries.
- Public library API with Rustdoc documentation.
